    Chat

    Connect

    Use your documents from Claude, ChatGPT, or your own code. Two ways in: the MCP server gives AI assistants tools to search and read your documents, and the HTTP API lets any app ask questions or fetch matching passages.

    1. Your addresses

    This is a local address. Claude Code, Claude Desktop, scripts and apps on this machine can use it, but claude.ai, ChatGPT and the Claude/OpenAI APIs connect from the internet and need a public HTTPS address: deploy behind a proxy and set PUBLIC_URL, or open a tunnel with cloudflared tunnel --url http://localhost:8080 and use the URL it prints.

    2. An API key

    Every client needs a key. It's shown once; this page fills it into the examples below until you leave it. Revoke keys under Admin.

    3. Pick your client

    MCP tools

    search(query, top_k)Passages that match the query, each with an id and page.
    fetch(id)The full text of the page a search result came from.
    ask(question, top_k)An answer written by the LLM configured in Setup, with sources.
    list_documents()The uploaded documents and their indexing status.

    Assistants usually call search and then fetch, and write the answer themselves. ask uses this server's LLM instead.
